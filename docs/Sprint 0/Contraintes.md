# Contraintes — Wystrelia's Bot

Le projet s'inscrit dans un cadre défini à l'avance. Certains choix nous ont été imposés.

## Les contraintes

Le projet doit respecter les exigences suivantes :

* **Technique** : La solution repose sur une pile technologique imposée :
* **Interface web (Frontend)** : React avec TypeScript.
* **Serveur (Backend)** : NestJS.
* **Base de données** : MySQL, associée à TypeORM pour la gestion des données.


* **Sécurité** : L'accès au tableau de bord doit être authentifié et strictement réservé aux administrateurs. Toutes les données saisies doivent faire l'objet de contrôles rigoureux avant tout traitement. La sécurité est une exigence fondamentale.
* **Qualité** : L'application doit garantir une haute fiabilité grâce à :
* Des **tests automatisés** à plusieurs niveaux (unitaires, d'intégration et fonctionnels).
* Le respect des normes d'accessibilité.


* **Méthodologique** : Le projet est réalisé par une équipe de trois personnes, en suivant la méthodologie **Agile/Scrum** avec une organisation en sprints.
* **Fonctionnelle** : L'outil est conçu comme une solution privée et sur mesure, dédiée exclusivement au serveur « Wystrelia » ; il n'est pas destiné à une diffusion publique.
